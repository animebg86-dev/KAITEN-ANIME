📋 Résumé du tutoriel créé pour votre GitHub :
1. 🌐 Ouvrir directement en ligne (Sans installation)
Sur PC : Cliquez simplement sur le lien du site dans n'importe quel navigateur.
Sur Mobile (Android / iOS) : Ouvrez le lien sur Chrome ou Safari et touchez « Ajouter à l'écran d'accueil » pour obtenir l'icône de l'app sur votre téléphone.
2. 💻 Lancer le projet sur PC depuis GitHub
Téléchargez le dossier ZIP depuis GitHub (ou faites git clone).
Installez Node.js si vous ne l'avez pas encore.
Ouvrez un terminal dans le dossier et lancez :
code
Bash
npm install
npm run dev
Ouvrez votre navigateur sur http://localhost:3000.
3. 📱 Tester en local sur Mobile (Même Wi-Fi)
En connectant votre PC et mobile au même Wi-Fi, il suffit de taper l'adresse IP de votre PC dans le navigateur du téléphone (ex: http://192.168.1.X:3000).
Ce fichier sera automatiquement affiché en première page lorsque les visiteurs consulteront votre dépôt GitHub.
